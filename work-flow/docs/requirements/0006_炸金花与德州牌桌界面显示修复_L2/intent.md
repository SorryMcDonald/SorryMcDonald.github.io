# 修复意图

修复炸金花与德州扑克牌桌的三类界面缺陷：界面显示不全、手牌遮挡其他元素、玩家昵称显示不完全。

## 范围

- 仅改动前端表现层：`public/app.js`、`public/styles.css`（炸金花）与 `public/dezhou.js`、`public/dezhou.css`（德州）。
- 不改动服务端逻辑、接口契约、数据库与部署配置。
- 不改动斗地主与锦标赛页面；两者各自加载独立样式表，本次改动不会外溢。

## 目标

1. 座位与底池分区互不重叠，窗口变矮时压缩中间区域而不是把座位推出桌沿或压住底池。
2. 手牌不覆盖底池、公共牌与邻座信息。
3. 昵称完整可见，不再被 `text-overflow:ellipsis` 截断。
