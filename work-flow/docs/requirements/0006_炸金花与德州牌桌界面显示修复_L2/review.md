改动集中在两套牌桌的表现层，且各自样式表互相隔离：`public/index.html` 只引用 `styles.css`，`dezhou.html` 只引用 `dezhou.css`，斗地主与锦标赛页面不受影响。

三处设计取舍已复核：

- 分区模型（对手贴上沿、自座贴下沿、中央区同时锚定两侧）取代原先按百分比定位的座位表。原因是叠放的多层 `@media` 密度覆盖会互相抵消，最终生效的是最后一块；把纵向定位交给 CSS 分区变量后，桌面变矮时压缩中央而不是把座位挤出桌沿。分区变量写在 `.felt` / `#seats` 元素上，因为中央区是座位容器的兄弟节点而非后代。
- 桌面由整椭圆改为圆角矩形。`border-radius:50%` 配 `overflow:hidden` 会裁掉正好位于上沿的对手座位，而座位在包围盒内，因此既有的几何断言无法发现；改为圆角矩形后角部仍有牌桌观感，整幅宽度均可用。
- 因座位不再做 Y 轴居中，所有内联了 `translate(-50%,-50%)` 的关键帧与变换都已改写为仅 `translateX(-50%)`：炸金花的 `compare-attacker`、`compare-target`、`.compare-focus`，德州的 `winner-double-flash`、`loser-shake`。

昵称处理按两套页面既有的可访问性约定分别实现：炸金花改为三行内换行显示，德州保留座位内视觉隐藏名（`.player-name-accessible`）供读屏与埋点使用、可见名走桌外名条。德州窄屏隐藏对手筹码数是有意取舍，「10,000 筹码」不可换行且宽于一个座位，座位身份由名条与徽章承载。

无服务端、接口、数据库或部署改动；不涉及外部写入与生产变更。
